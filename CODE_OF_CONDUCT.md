# Code of Conduct

RAGShield is an open-source security project. We expect contributors to be respectful, constructive, and focused on defensive security outcomes.

## Expected Behavior

- Be professional and helpful.
- Share feedback clearly and respectfully.
- Keep discussions focused on improving the tool.
- Respect privacy and do not publish sensitive data.

## Unacceptable Behavior

- Harassment, hate speech, or personal attacks.
- Publishing private information or secrets.
- Adding malicious code or offensive automation aimed at unauthorized targets.
- Repeated disruption of issues, pull requests, or discussions.

Maintainers may remove content, reject contributions, or block users who violate these expectations.
