# Contributing

Thanks for helping improve RAGShield.

## How to Contribute

1. Fork the repository.
2. Create a focused branch.
3. Keep changes small and reviewable.
4. Add or update detection examples when you add scanner logic.
5. Open a pull request with a clear summary and testing notes.

## Rule Contributions

Detection rules should include:

- Risk category
- OWASP LLM mapping
- Example payload or evidence
- Recommended remediation

## Ground Rules

- Keep the project defensive and educational.
- Do not add exploit automation against real third-party services.
- Do not commit secrets, API keys, tokens, or private test data.
