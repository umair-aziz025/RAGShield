# Security Policy

## Supported Version

Security fixes are handled on the `main` branch.

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

Email: `umairaziz682@gmail.com`

Include:

- Description of the issue
- Steps to reproduce
- Impact and affected files
- Suggested fix, if known

## Secret Handling

RAGShield runs locally in the browser and does not require API keys. Do not paste real production secrets into demos, screenshots, public issues, or shared reports.
